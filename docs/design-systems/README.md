# Site designs

The DESIGN.md files behind Settings → Branding → Site design, from
[shadcn.io/design](https://www.shadcn.io/design). Each is applied as a set of
colour and shape settings in `src/app/globals.css` (`[data-design="…"]`), with
its font chosen in `src/app/fonts.ts` (`pageFontFace`).

All designs are applied on light pages (owners' choice): GitHub, Linear and
Framer document dark-only sites and are turned light; GitHub keeps black
buttons; Claude uses Source Serif 4 for Copernicus.
